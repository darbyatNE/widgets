<h1 class="title-row">S&amp;P 500 Regression Trend Lines
<details class="info"><summary title="About this chart" aria-label="About this chart">i</summary><div class="info-body">
<p>Each line is a least-squares regression fit through the monthly S&amp;P 500 closes, from its <strong>start month</strong> through the <strong>latest reading</strong> (the December 31, 2025 close). Start months can run from the first month in the data up to a few months before the latest reading. Use the controls below the chart to choose which lines are drawn. Very recent starts fit only a few points, so their growth rates are noisy.</p>
<ul>
<li><strong>Linear:</strong> a straight line in index points. Poor over long spans, because the index compounds.</li>
<li><strong>Exponential (log-linear):</strong> constant percentage growth, a straight line on a log axis.</li>
<li><strong>Log-quadratic (default):</strong> ln(price) = a + b·t + c·t². This lets the growth rate speed up or slow down over the window, so it tracks the "middle" of the price history more closely than a single constant rate. <em>Growth @ latest</em> is each fit's annual % growth rate at the latest reading. <em>Avg growth</em> is the fitted line's compound annual growth rate (CAGR) over its window.</li>
</ul>
</div></details>

```js
const raw = await FileAttachment("data/sp500_monthly.csv").text();
// Charts end at the Dec 2025 close; later rows in the CSV are ignored.
const END_DATE = new Date("2025-12-31T23:59:59");
const data = d3.csvParseRows(raw)
  .filter((r) => r.length >= 2 && r[0])
  .map(([d, v]) => ({date: new Date(d + "T00:00:00"), close: +v.replace(/,/g, "")}))
  .filter((d) => !isNaN(d.date) && isFinite(d.close) && d.date <= END_DATE)
  .sort((a, b) => a.date - b.date);

const endPoint = data[data.length - 1];
// A start month needs at least MIN_POINTS monthly closes through the latest reading to fit a line.
const MIN_POINTS = 3;
const fmtMonth = d3.utcFormat("%b %Y");
const fmtDate = d3.timeFormat("%m/%d/%Y");
const fmtNum = d3.format(",.2f");

// Candidate regression start months, independent of fit type so the range selection is kept.
const starts = data
  .map((d, i) => ({i, startDate: d.date, year: d.date.getFullYear(), key: d3.timeFormat("%Y-%m")(d.date)}))
  .filter((s) => data.length - s.i >= MIN_POINTS);
```

```js
import {FITS, fit as fitTo} from "./components/regression.js";
const fit = (points, model) => fitTo(points, model, endPoint.date);
```

```js
const model = FITS[fitType];
const useLog = model.log;
// Only the exponential fit has a constant % rate; linear and log-quadratic rates vary over time.
const isCurvedRate = !(model.log && model.degree === 1);
const regressions = starts.map(({i, key, year, startDate}) => {
    const pts = data.slice(i);
    const f = fit(pts, model);
    // Straight lines need only their endpoints; curved fits are sampled every month.
    const curve = (model.log || model.degree > 1 ? pts : [pts[0], pts[pts.length - 1]])
      .map((p) => ({key, date: p.date, value: f.predict(p.date)}));
    return {
      key,
      year,
      startDate,
      n: pts.length,
      slopePerYear: f.growthNow,
      avgGrowth: f.avgGrowth,
      growthAt: f.growthAt,
      r2: f.r2,
      rmsPct: f.rmsPct,
      fittedEnd: f.predict(endPoint.date),
      predict: f.predict,
      i,
      curve
    };
  });
```

```js
const selectedSet = new Set(selectedKeys);
const shown = regressions.filter((r) => selectedSet.has(r.key));
const fmtSlope = (v) => (isFinite(v) ? d3.format("+.2%")(v) + "/yr" : "n/a");

// A log axis bends straight lines and can't show values <= 0, so sample every month and keep the positive part.
const curveOf = (r) =>
  logScale && !useLog
    ? data.slice(r.i).map((p) => ({key: r.key, date: p.date, value: r.predict(p.date)})).filter((c) => c.value > 0)
    : r.curve;
const shownCurves = shown.map((r) => ({r, curve: curveOf(r)}));
```

```js
// Starts repeat every 1, 3 or 12 months, counted from the chosen first start month.
const fromIdx = range.fromYear * 12 + MONTHS.indexOf(range.fromMonth);
const toIdx = range.toYear * 12 + MONTHS.indexOf(range.toMonth);
const step = {Monthly: 1, Quarterly: 3, Yearly: 12}[range.freq];
const selectedKeys = starts
  .filter((s) => {
    const idx = s.year * 12 + s.startDate.getMonth();
    return idx >= fromIdx && idx <= toIdx && (idx - fromIdx) % step === 0;
  })
  .map((s) => s.key);
display(html`<p class="range-note">${selectedKeys.length ? `${selectedKeys.length} regression line${selectedKeys.length === 1 ? "" : "s"} drawn.` : "No lines in this range. The first start must be on or before the last start."}</p>`);
```

<h2 class="title-row">Growth rates — ${fitType}
<details class="info"><summary title="About this chart" aria-label="About this chart">i</summary><div class="info-body">
<p>Annual growth rate (% per year) implied by each selected regression. In the <em>By start month</em> view, each start month on the x-axis has two values taken from the same trend line:</p>
<ul>
<li><strong style="color:#1f77b4">Blue: average over window.</strong> The trend line's compound annual growth rate (CAGR) from its start month to the latest reading. If you had bought at the trend value in that month, this is the yearly return the trend delivered through December 2025.</li>
<li><strong style="color:#d62728">Red: at latest.</strong> How steep the trend line is at its right-hand end, as % per year. This is the pace the trend was growing at in December 2025.</li>
</ul>
<p><strong>Red above blue</strong> means that trend has been speeding up. <strong>Red below blue</strong> means it has been slowing down.</p>
<p>The <em>Over time</em> view plots each line's growth rate across its whole window.</p>
<p><em>Exponential</em> fits grow at a constant rate, so they show a single line. A <em>Linear</em> fit adds a fixed number of points per year, so its % rate falls as the index rises. Its average (CAGR) is shown only where the fitted line starts above zero.</p>
</div></details>
</h2>

```js
const growthSize = chartSize(vp, width, {rail: true, reserve: 318, min: 240, mobile: 340});
const fmtG = (v) => (isFinite(v) ? d3.format(".1%")(v) : "n/a");
const gAxis = {grid: true, label: "Annual growth (%/yr)", tickFormat: (v) => d3.format(".0%")(v)};
const colorOpts = {type: "time", scheme: "turbo", domain: d3.extent(starts, (s) => s.startDate), legend: true, label: "Regression start month"};
const isCurved = isCurvedRate;

let growthPlot;
if (growthView === "Over time") {
  // Sample quarterly so a few hundred curved lines stay responsive.
  const gCurves = shown.map((r) => ({
    r,
    pts: data.slice(r.i).filter((p, k, a) => k % 3 === 0 || k === a.length - 1).map((p) => ({date: p.date, g: r.growthAt(p.date)})).filter((p) => isFinite(p.g))
  }));
  growthPlot = Plot.plot({
    width: growthSize.width,
    height: growthSize.height,
    marginLeft: 60,
    y: gAxis,
    x: {label: null},
    color: colorOpts,
    marks: [
      Plot.ruleY([0], {stroke: "#888"}),
      ...gCurves.map(({r, pts}) => Plot.line(pts, {x: "date", y: "g", stroke: () => r.startDate, strokeWidth: 1, strokeOpacity: 0.7})),
      Plot.tip(
        gCurves.flatMap(({r, pts}) => pts.map((p) => ({...p, r}))),
        Plot.pointer({x: "date", y: "g", title: (d) => `Start: ${fmtMonth(d.r.startDate)}\n${fmtMonth(d.date)}: ${fmtG(d.g)}/yr`})
      )
    ]
  });
} else {
  const rows = shown.flatMap((r) =>
    isCurved
      ? [
          {startDate: r.startDate, g: r.avgGrowth, series: "Average over window"},
          {startDate: r.startDate, g: r.slopePerYear, series: `At latest (${fmtDate(endPoint.date)})`}
        ]
      : [{startDate: r.startDate, g: r.slopePerYear, series: "Constant rate"}]
  );
  growthPlot = Plot.plot({
    width: growthSize.width,
    height: growthSize.height,
    marginLeft: 60,
    y: gAxis,
    x: {label: "Regression start month"},
    color: {legend: true, domain: [...new Set(rows.map((d) => d.series))], range: ["#1f77b4", "#d62728"]},

      Plot.line(rows, {x: "startDate", y: "g", stroke: "series", z: "series", strokeWidth: 1.5}),

  });
}
```

<p class="ws-note"><strong>Fit quality.</strong> <em>RMS error</em> is the root-mean-square percentage gap between each monthly close and its fitted value. It is measured the same way for every fit type, so it's the fairest comparison. R² is computed on the fitted scale (price for Linear, ln(price) for the log fits), so it isn't comparable across fit types.</p>
